Set up Live Link

Checking Bluetooth setup…

  1. 1
    Install beacio Install the free Safari Bluetooth extension from the App Store.
    Install beacio
  2. 2
    Enable beacio and its website permission In Safari, tap aA → Manage Extensions → beacio, turn it on, then choose Allow on Every Website.
  3. 3
    Open pairing on the comma While parked, open Galaxy → Bluetooth, turn Bluetooth on, then tap Pair a Phone.
  4. 4
    Open the secure Live Link page Open the HTTPS page in Safari, connect, and choose StarPilot. Pair a Phone authorizes it automatically.
    Continue in secure Galaxy

Installed beacio, but Live Link still cannot see it? In Safari, tap aA → Manage Extensions → beacio. Make sure it is on and set to Allow on Every Website. You can also check Settings → Apps → Safari → Extensions → beacio. Then return here and reload. Private Browsing and in-app browsers cannot use the extension.
